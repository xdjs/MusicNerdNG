font "KoHo" declared → falls back to system sans (KoHo never loads)
  • Reality vs intent — font: all buttons declare font-sans / "KoHo", but KoHo is never loaded (no next/font, no @font-face), so every specimen here renders in the system sans stack — which is what ships.
  • Deviation — no hover on default: stock shadcn ships hover:bg-primary/90; it was removed in button.tsx:12, so the primary button has no hover feedback. Every other variant keeps its hover.
  • Semantic layer is 100% stock slate: --primary/--secondary/--accent/--destructive are unmodified shadcn values in both :root and .dark — brand color (maroon/pastypink/pastyblue) never reaches these tokens.
  • Three parallel button systems: this cva Button, the legacy .pink-btn, and a hand-rolled ThemeToggle <button>.
