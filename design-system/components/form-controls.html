The real Input is heavily stripped: no border border-input, no fixed height, and no focus-visible ring — so it renders borderless with no focus affordance (shown on a --muted field so the box is visible). It also uses text-base where stock shadcn uses text-sm. Every form must re-add chrome via className — that's the restyled input on the left.

Light → dark accent swap. The checked box is pink #ff9ce3 in light and cyan #2ad4fc in dark — hardcoded in globals.css as [data-state="checked"] overrides, not from the semantic --primary token (which stays slate). The unchecked border still follows --primary. #ff9ce3 is the real on-screen pink (57 uses); it isn't in any palette.
