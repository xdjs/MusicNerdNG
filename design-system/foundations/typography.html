Typography

Stock Tailwind type scale rendered in the system sans stack the app actually ships. No custom fontSize scale, no font tokens — the only bespoke type is two hand-rolled fluid clamp() display headings.

i
KoHo is declared but never loads. .koho-extralight (200), .koho-light (300) and the shipping .pink-btn all declare font-family: "KoHo", sans-serif — but there is no next/font, <link>, @font-face or font package anywhere in the app, so every one silently falls back to system sans-serif. Everything below renders in the real fallback stack. (KoHo only loads on two standalone public/*privacy.html legal pages.)
