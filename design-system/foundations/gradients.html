Two vocabularies for the same pink→purple wash. The hero uses raw hex (from-[#ef95ff] to-[#7c3aed]); the press thumb uses the pastypink token + Tailwind purple-900. Note the palette pink here is #ef95ff — not the #ff9ce3 pink users actually see on the wordmark. Base --radius: 0.5rem; swatch corners are illustrative. KoHo is declared but never loads, so all type renders in the system sans stack.
